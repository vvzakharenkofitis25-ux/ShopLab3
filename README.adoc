== 1. Мета роботи
Відпрацювати навички володіння класами, об'єктами та іншими механізмами ООП у Java (успадкування, інкапсуляція, поліморфізм). Реалізувати роботу з колекціями даних та механізмом файлового введення-виведення (серіалізації/десеріалізації) на прикладі консольного інтернет-магазину.

== 2. Опис виконання та архітектура застосунку
Проєкт складається з таких основних компонентів:
* **`Product`**: клас-сутність, що описує товар (ID, назва, ціна, категорія). Реалізує інтерфейс `Serializable`.
* **`Cart`**: клас кошика, який використовує колекцію `Map<Product, Integer>` для зберігання товарів та їх кількості, а також містить метод генерації рахунку-фактури.
* **`ShopService`**: сервісний клас для управління каталогом товарів, реалізації пагінації (`showCatalogPage`) та збереження/завантаження стану за допомогою Java Serialization (`ObjectOutputStream` / `ObjectInputStream`).
* **`Main`**: головний клас із консольним меню користувача для взаємодії з програмою.

== 3. Висновки
Під час виконання лабораторної роботи було закріплено навички проєктування об'єктно-орієнтованої структури на Java, використання колекцій (`List`, `Map`), а також реалізовано механізм збереження стану програми за допомогою серіалізації об'єктів.

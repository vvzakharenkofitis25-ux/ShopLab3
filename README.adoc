== Лабораторна робота №3: Консольний застосунок та серіалізація
* **Мета:** Відпрацювати навички роботи з класами, колекціями та файловим введенням-виведенням (серіалізація/десеріалізація).
* **Реалізація:** Створено консольний інтернет-магазин із пагінацією каталогу, кошиком, генерацією рахунку-фактури та збереженням стану у файл (`shop_data.ser`).

== Лабораторна робота №4: Поліморфізм. Абстрактні класи. Enum. Records.
* **Мета:** Отримати практичні навички використання поліморфізму, абстрактних класів, перерахувань (`enum`), методів `Object`, копіювання об'єктів та `records`.
* **Реалізація:**
  1. Базовий клас `Product` перетворено на абстрактний із поліморфними методами.
  2. Додано класи-нащадки `Electronics` та `Clothing`.
  3. Створено `enum` `OrderStatus` для керування статусами замовлень.
  4. Перевизначено `toString()`, `equals()`, `hashCode()` та реалізовано клонування (`Cloneable`) для глибокого копіювання кошика.
  5. Створено `record` `SearchCriteria` для параметрів пошуку.
  6. Використано `instanceof` із патерн-матчингом для обробки специфіки товарів.

== Як запустити
1. Відкрити проєкт у IntelliJ IDEA.
2. Запустити файл `Main.java` із пакета `main`.


== Лабораторна робота №5: Обробка винятків. Узагальнення. Optional.
* **Мета:** Отримати практичні навички створення та обробки власних виняткових ситуацій, використання узагальнених типів (Generics) з обмеженнями та типу Optional.
* **Реалізація:**
  1. **Ієрархія винятків:** Створено власний базовий виняток `ShopException`, checked-виняток `ProductNotFoundException` та unchecked-виняток `InvalidPriceException`.
  2. **Обробка винятків:** Реалізовано обробку помилок у блоках `try-catch` та використання `try-with-resources` для безпечної роботи з потоками вводу-виводу.
  3. **Generics (Узагальнення):** Створено узагальнений клас `Repository<T extends Identifiable, ID>` та застосовано обмеження типів (`bounded type parameter`).
  4. **Тип Optional:** Замінено традиційне повернення `null` на використання `Optional` разом із методом `orElseThrow` для безпечного пошуку сутностей.
  5. **Wildcards:** Написано узагальнений метод із використанням wildcard (`? extends Product`) для обробки колекцій різнотипних елементів ієрархії.
